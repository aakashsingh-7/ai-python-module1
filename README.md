# AI & Python - Module 1

Beginner Python programs written during Module 1 (Introduction to AI & Python) of my internship.

## Programs

| File | Concept practiced |
|------|-------------------|
| `01_variables_and_input.py` | Variables, data types, input/output |
| `02_even_odd_checker.py` | Conditionals (`if / elif / else`) |
| `03_multiplication_table.py` | `for` and `while` loops |
| `04_functions.py` | Functions, parameters, return values |
| `05_lists.py` | Lists, list methods, comprehensions |
| `06_simple_ai_idea_spam_filter.py` | Rule-based classification (intro to AI thinking) |

## How to run

1. Install Python 3 from https://www.python.org/downloads/
2. Open a terminal in this folder
3. Run any program, for example:
   ```
   python 01_variables_and_input.py
   ```

## What I learned

- The difference between AI, Machine Learning, and Deep Learning
- Core Python building blocks: variables, loops, functions, and lists
- How to organize code and publish it on GitHub
